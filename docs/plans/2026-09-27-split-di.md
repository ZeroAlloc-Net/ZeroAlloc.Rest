# Split DI out of ZeroAlloc.Rest core (#336) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the DI and `IHttpClientFactory` integration out of `ZeroAlloc.Rest` into a new
`ZeroAlloc.Rest.DependencyInjection` package, so core depends only on `ZeroAlloc.Results` and
`ZeroAlloc.Collections`, and the generator emits DI code only when the DI package is referenced.

**Architecture:** The generator reads one value-equatable `bool` from the compilation: whether
`ZeroAlloc.Rest.DependencyInjection.DependencyInjectionMarker` resolves. With it, output is as today;
without it, the client and its constructor only. The moved types keep the `ZeroAlloc.Rest` namespace,
so the migration is one package reference. The Resilience bridge is all DI, so it references the DI
package instead of core.

**Tech Stack:** .NET 10, Roslyn incremental generators (netstandard2.0), xunit, PublicApiAnalyzers,
Microsoft.DotNet.ApiCompat.Tool, GitHub Actions, Native AOT.

**Spec:** `docs/plans/2026-09-27-split-di-design.md`. Read it before any task.

## Global Constraints

- Core `ZeroAlloc.Rest` package dependencies: exactly `ZeroAlloc.Results` and `ZeroAlloc.Collections`. Nothing from `Microsoft.Extensions`.
- DI package: `ZeroAlloc.Rest.DependencyInjection`, depends on core and `Microsoft.Extensions.Http`, does not bundle the generator.
- Marker: `public static class ZeroAlloc.Rest.DependencyInjection.DependencyInjectionMarker`, `[EditorBrowsable(EditorBrowsableState.Never)]`, no members.
- Moved types keep namespace `ZeroAlloc.Rest`. DI helpers formerly on `GeneratedRestClient` move to `ZeroAlloc.Rest.GeneratedRestClientRegistration`.
- Removed outright: `RestSerializerAdapter<T>`, the `ZeroAlloc.Serialisation` and `ZeroAlloc.ValueObjects` package references of core.
- **No suppressions of any kind**: no new `NoWarn`, `#pragma warning disable`, `[SuppressMessage]`, `.editorconfig` severity downgrades or `<WarningsNotAsErrors>`. Existing ones in files you only touch may stay. If only a suppression would work, stop and report.
- Build: `dotnet build ZeroAlloc.Rest.slnx -c Release -p:Version=9.9.9-local.<sha>` with 0 warnings; tests `dotnet test ZeroAlloc.Rest.slnx -c Release --no-build` all pass, as CI runs them.
- Local packs use version `9.9.9-local.<short sha>` only, never a real version. Before packing into `artifacts/local`, delete its contents so only one version is present.
- Commit messages: conventional commits, body lines at most 100 characters, no nested parentheses, never write `typeof(X)` with parentheses, no `claude.ai` links. End each body with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Public API: removed core members become `*REMOVED*<line>` entries in `src/ZeroAlloc.Rest/PublicAPI.Unshipped.txt`; new DI API goes in the DI package's `PublicAPI.Unshipped.txt`. RS0016/RS0017 are errors.
- Do not touch release PR #366, other repos, or `CHANGELOG.md`.

```csharp
internal const string DependencyInjectionMarkerName =
    "ZeroAlloc.Rest.DependencyInjection.DependencyInjectionMarker";

// in Initialize, after clientModels:
var dependencyInjection = context.CompilationProvider
    .Select(static (compilation, _) => compilation.GetTypeByMetadataName(DependencyInjectionMarkerName) is not null)
    .WithTrackingName("DependencyInjectionEnabled");

context.RegisterSourceOutput(clientModels.Combine(dependencyInjection), static (ctx, pair) =>
{
    var (model, dependencyInjectionEnabled) = pair;
    ClientEmitter.Emit(ctx, model, dependencyInjectionEnabled);
    if (dependencyInjectionEnabled)
        DiEmitter.Emit(ctx, model);
});
```
